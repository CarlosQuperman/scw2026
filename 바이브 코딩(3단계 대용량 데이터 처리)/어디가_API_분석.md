# 대학어디가 API로 수시 등급 계산 — 가능 여부 분석

## 결론
**대학어디가를 API로 불러 계산하는 것은 불가능.** 대신 **업로드한 상담카드 자료만으로 ‘입결 대비 위치’와 ‘수능최저 충족’을 추정하는 기능은 가능**해서 그것을 구현했다. **대학별 환산등급 계산은 두 방법 모두 불가.**

## 1. 대학어디가(adiga.kr) — 불가
- 공개 Open API가 없다. 성적분석은 회원 로그인 후 ‘학생부입력’에 성적을 넣고 ‘대학별성적분석’ 화면 안에서만 결과를 보여 준다.
- 사이트가 자동 접근(robots)을 막고 있어 앱스크립트로 화면을 긁어 오는 방식도 기술적·약관상 쓸 수 없다.
- 교사용 ‘샘어디가’도 참여 학교 교사에게만 열린 웹 서비스이고 외부 연동 API는 없다.

## 2. 공공데이터포털의 대교협 API — 목적에 안 맞음
- 한국대학교육협의회가 공공데이터포털에 연 API는 대학알리미 공시 자료(대학 기본정보, 학과정보, 신입생 경쟁률·충원율 등)다.
- 전형별 입결(50%·70%컷)이나 대학별 환산 산식은 들어 있지 않아 수시 등급 계산에는 쓸 수 없다.

## 3. 업로드한 HTML 자료로 할 수 있는 것 — 구현함
| 항목 | 자료 현황 (27,117행 기준) | 구현 |
|---|---|---|
| 입결 대비 위치 | 등급형 입결(50%·70%컷 또는 평균)이 있는 행 16,926개 | 안정·적정·상향·소신 추정 |
| 수능최저 충족 | 최저가 있는 행 6,649개 중 규칙 문장을 읽을 수 있는 행 5,808개 | 모의 등급으로 충족·미충족 추정 |
| 점수형 입결 | 900점대 등 점수로 공시된 행 일부(예: 제주대·목포대 종합) | ‘점수형 입결(비교 불가)’로 표시 |
| 대학별 환산등급 | 반영 교과·학년 비율·진로선택 반영 방식 **자료 없음** | 계산 안 함. 학생이 입학처 계산기나 어디가 성적분석 결과를 ‘대학별 환산등급’ 칸에 적으면 그 값으로 비교 |

## 4. 한계 (학생에게도 알려야 할 것)
- 입결은 전년도 결과다. 모집인원·전형 변화, 충원 여부에 따라 달라진다.
- 학생부종합은 서류 평가 비중이 커서 등급 비교는 참고만 — 화면에도 그렇게 표시.
- 수능최저 추정은 과목 지정(미적분/기하, 과탐), 계열별 다른 기준, 탐구 반영 방식 일부를 단순화했다.

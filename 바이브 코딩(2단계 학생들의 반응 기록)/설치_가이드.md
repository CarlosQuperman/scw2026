# 형성평가 → 구글 시트 기록: 설치 가이드

## 필요한 파일은 2개 (+ 설정)
| 파일 | 넣는 곳 | 역할 |
|---|---|---|
| `index.html` | Apps Script 편집기 → 파일 추가(+) → HTML → 이름 `index` | 학생 화면 (학번·이름 입력, 채점 및 제출) |
| `Code.gs` | Apps Script 편집기 기본 `Code.gs`에 덮어쓰기 | 화면 띄우기, 서버 채점, 시트 기록 |

시트 머리글·서식은 `setup()`이 자동으로 만든다. 시트에 손으로 설정할 것은 없다.

## 순서
1. 새 구글 시트 만들기 → **확장 프로그램 → Apps Script**
2. `Code.gs` 붙여넣기, `index` HTML 파일 추가 후 붙여넣기 → 저장
3. 함수 목록에서 `setup` 선택 → **실행** → 권한 승인
   - "Google에서 확인하지 않은 앱" 경고 → 고급 → (안전하지 않음)으로 이동 → 허용
   - 시트에 `이동식 크레인 제출` 탭이 생기면 성공
4. (선택) `testSubmit` 실행 → 테스트 줄 확인 후 삭제
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나** (학생에게 시트 권한을 주지 않아도 기록됨)
   - 액세스 권한: 학생이 학교 계정으로 로그인하면 **[학교 도메인] 내 모든 사용자**, 로그인 없이 쓰려면 **모든 사용자**
6. 나온 웹 앱 URL(`…/exec`)을 학생에게 공유 (클래스룸·QR)

## 자주 막히는 곳
- **코드를 고쳤는데 학생 화면이 그대로**: 배포 → 배포 관리 → 연필(수정) → 버전: **새 버전** → 배포. 저장만 해서는 `/exec` 주소에 반영되지 않는다. (URL은 그대로 유지됨)
- **'모든 사용자'가 선택지에 없음**: 학교 Workspace 관리자가 외부 공개를 막아 둔 경우. 도메인 내 사용자로 배포하고 학생은 학교 계정으로 접속.
- **문제·정답을 바꿀 때**: `index.html`의 `Q` 배열과 `Code.gs`의 `QUIZZES.crane.answers`를 **둘 다** 고친다. (점수는 서버 정답 기준으로 기록)
- **다른 지문 추가**: `QUIZZES`에 새 키를 넣고, 그 HTML의 `QUIZ_ID`를 같은 값으로. 지문마다 시트 탭이 따로 생긴다.

## HTML을 앱스크립트 밖에서 열 때 (제미나이 공유 링크, 깃허브 페이지 등)
`index.html` 안 `var WEB_APP_URL = "";`에 웹 앱 주소(`…/exec`)를 넣는다. 이때 액세스 권한은 **모든 사용자**여야 한다(외부 페이지는 로그인 정보를 넘기지 않음).

## 설계상 결정 (수업 운영에 영향)
- **채점은 제출 후에만 공개**: 기존 '채점' 버튼을 '채점 및 제출'로 합쳤다. 채점을 먼저 보여 주면 정답을 보고 고친 뒤 제출할 수 있기 때문.
- **제출 후 답 잠금, '다시 풀기'로 재제출 가능**: 재제출은 막지 않고 `제출 회차`로 구분한다. 평가 점수는 **1회차**만 쓰면 된다 (필터: 제출 회차 = 1).
- **서버 재채점**: 학생 브라우저가 보낸 점수는 믿지 않고, 고른 답만 받아 서버 정답으로 O/X를 매긴다.
- **동시 제출 잠금**: 40명이 한꺼번에 눌러도 줄이 겹치지 않도록 LockService 사용.
- **학번 검사**: 숫자 4~6자리. 학교 학번 체계가 다르면 `index.html`과 `Code.gs`의 `\d{4,6}` 두 곳을 함께 바꾼다.
